Install

      
With the xquirks integration you need no download: it offers each of these files under Settings > System > Repairs and installs it once you confirm. Install from the Marketplace

      
By hand: needs the Home Assistant release the files were built for, or newer.

      
    
        
  1. Download each file above from its GitHub page ("Download raw file").
    2. 
        
  2. Copy only these files (never the whole repo) into your custom quirks folder, for example /config/custom_zha_quirks/. On HA OS the File editor, Samba or SSH app can do that. ZHA loads every file in the folder and each file claims every device with its Zigbee fingerprint.
    3. 
        
  3. Point ZHA at the folder in configuration.yaml:
          
    zha:
  custom_quirks_path: /config/custom_zha_quirks/
    
        
    4. 
        
  4. Restart Home Assistant.
    5. 
      

      
When zha-device-handlers gains a quirk for one of these devices, the quirk that ships with ZHA takes over and the file steps aside on its own. You can delete the file then. To remove a file: delete it, restart Home Assistant and remove the entities the device no longer has. The xquirks integration can take over files you copied by hand.

      
ZHA logs "Loaded custom quirks. Please contribute them to zha-device-handlers" for every custom quirk. For these files please report problems in this repo instead, or test an open upstream pull request for your device and report there.
